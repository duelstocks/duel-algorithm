How this was calculated

Every figure above is derived directly from each company's SEC EDGAR filings — no analyst estimates. AMD's report is dated 2026-06-27; NVDA's is dated 2026-07-26 (most recent filing available for each company at the time this snapshot was taken).

The overall score is DUEL Score = Σ ( Wᵢ × Nᵢ ) × 100, where Wᵢ is each factor's weight (sum = 1.0, see the table above) and Nᵢ is that factor's soft relative score: t = (a − b) / (|a| + |b|), then N_a = 0.5 + 0.5·t, N_b = 0.5 − 0.5·t — a narrow gap between two companies stays close to a draw, and only a genuinely wide gap approaches a full win. This scoring formula itself is unchanged since the last update; what changed this time is the factor set and weights (see below).

Debt / Equity = (Short-Term Debt + Long-Term Debt) / Stockholders' Equity, inverted (lower is better) — it replaces Receivables Turnover, which is no longer part of the model. When book equity is zero or negative (e.g. from large buybacks), Debt/Equity is undefined rather than misleadingly low — shown as a dash, scored with the same missing-data rule as any other absent factor. The exact code (normalize_pair, compute_duel, check_consistency_flags) is open-source in the GitHub repository alongside the SEC data-fetching code, so you can verify every number yourself.

Consistency flags (informational only)
